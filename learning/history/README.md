# 이전 기록 보관

이 파일들은 자료 정리 직전의 원본을 그대로 복사한 기록이야. 현재 지침이나 기능 명세로 사용하지 않아.

- [이전 학습 기록](learning-direction-before-preparation.md)
- [이전 AGENTS 지침](agents-before-preparation.md)
- [이전 CLAUDE 지침](claude-before-preparation.md)
- [이전 library 명세](library-spec-before-preparation.md)

원래 위치와 SHA-256은 [보관 명세](archive-manifest.json)에 기록했어. 원문을 보존했으므로 보관본 안의 상대 링크는 원래 위치 기준일 수 있어. 현재 안내는 [학습 기록](../../LEARNING_DIRECTION.md)과 [자료 입구](../../START_HERE.md)를 사용해.

study/conversation.txt는 원래 위치에 그대로 두었어.
