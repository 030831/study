# 학습 메모

빈칸을 전부 채우는 숙제가 아니야. 한 세션에서 중요한 것만 적어.

- 날짜 / 프로젝트 / 과제:
- 오늘 완성하거나 확인할 행동 하나:
- 시작 전에 예상한 처리 흐름:
- 실제로 바꾼 파일 또는 작성한 설명:
- 확인한 결과와 근거(테스트·SQL·로그·스크린샷):
- 사용한 도움(공식 문서 / 개념 설명 / 힌트 / 구체적인 수정 지시):
- 예상과 달랐던 점 또는 아직 모르는 것:
- 다음에 혼자 다시 해볼 변경 하나:

상태는 `아직 확인 안 함 / 안내받아 수행 / 스스로 수행 / 다른 상황에 적용` 중 해당하는 것으로 적어도 돼. 통과 점수나 취업 수준으로 해석하지 않아.
