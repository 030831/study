# 자료 점검 결과

점검일: 2026-09-07. 이 결과는 학습 자료의 근거와 구성에 대한 점검이야. 사용자의 실력이나 프로젝트 전체 품질을 판정한 것은 아니야.

## 최초 자료 준비에서 확인한 내용

- 공개 두 저장소의 확인한 커밋에서 핵심 코드/테스트/README 20개와 library의 소스·설정 13개를 읽은 범위를 출처 명세에 기록했어. 공개 링크는 해당 커밋에 고정했어.
- 공식자료 지도 14개 항목은 관련 본문을 확인하고 버전과 적용 범위를 구분했어. 모든 문서를 완독하거나 예제를 실행한 것은 아니야.
- 현재 소스와 기존 사용자 보고를 구분했고, 대출 생성자가 아직 없다는 상태를 유지했어. 이전 생성자 과제와 새 진단 과제가 서로 덮어쓰지 않도록 했어.
- 진단 7개와 힌트·리뷰 기준의 식별자를 비교했어. 관계 예시의 기록 수, 부분 반납 후 옛 요청 재시도, 정상 성공과 실패 원자성 검증의 차이를 별도로 검토했어.
- 최초 준비 당시 이 보고서를 제외한 안내 문서 17개의 로컬 링크 51개가 최종 위치에서 실제 대상으로 연결되는지 확인했어. 외부 링크 표기는 47개이며, 이 수는 모든 URL의 접속을 다시 검사했다는 뜻은 아니야.
- 현재 안내 문서의 UTF-8 읽기, 대체문자, 코드 블록과 접기 태그의 짝, 임시 작업 경로 노출을 검사했어.
- 이전 문서 4개의 보관본은 원본과 SHA-256이 일치해. 원문에 있던 상대 링크와 과거 지시는 수정하지 않고 보존했어.
- 근거로 읽은 library 파일 13개는 당시 해시와 일치했어. 최종 배치 전후에도 소스·빌드 설정·원문 대화 등 22개 파일의 해시가 같았어.

## 아직 확인하지 않은 것

- 이번 작업에서 빌드·테스트·서버·DB를 실행하지 않았어. 새 테스트가 통과했다고 주장하지 않아.
- 진단 문제는 아직 사용자가 수행하지 않았어. 난이도와 다음 순서는 실제 시도에 맞춰 조절해야 해.
- 공개 저장소 전체의 버그·보안·성능을 감사하지 않았어. 특정 코드의 존재를 독립적인 구현 능력의 증거로 일반화하지 않아.
- 채용 공고는 예시 한 건이야. 모집 여부와 목표 회사의 요구는 실제 지원 시 다시 확인해야 해.
- 보관본 내부의 오래된 링크는 현재 안내 문서의 링크 검사에서 제외했어.

근거 목록은 [출처 명세](source-manifest.json), 원본 보관 목록은 [보관 명세](history/archive-manifest.json)에 있어. 시작할 때는 [자료 입구](../START_HERE.md)만 열면 돼.
