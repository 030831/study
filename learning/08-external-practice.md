# Spring·JPA 실습자료 선정 기준과 사용자 제공 참고자료

수정일: 2026-09-07. 요청한 Spring·JPA 실습과 맞지 않았던 추가 추천 세 개는 제외했어. 현재 새로 추천하는 외부 실습자료는 없어.

## 사용자 제공 참고자료

[reboot-test](https://github.com/guswlsdl0121/reboot-test)는 사용자가 먼저 찾아 공유한 저장소야. 내가 새로 발굴한 추천 자료로 세지 않아.

앞선 조사에서는 판매 게시글 CRUD의 Spring Boot·JPA 구현과 수동 HTTP 요청 파일을 확인했어. 확인 기준은 main의 `2604b8bfe093a8aa29050b861c91ae4d856bb4bd`이며, 빌드·DB·테스트 실행은 하지 않았어.

## 다음 자료를 고를 기준

- Spring·JPA로 서버 기능을 직접 구현하거나 수정하는 실습인지 확인한다.
- 실제 코드·명세에서 연관관계, 영속성, 트랜잭션, 쿼리 등 무엇을 연습하는지 확인한다.
- 순수 Java 콘솔 문제나 SQL 단독 연습을 이번 요청의 대체 자료로 추천하지 않는다.
- Spring을 선택할 수 있다는 사실만으로 Spring·JPA 학습자료라고 판단하지 않는다.
- 사용자가 제공한 자료와 새로 찾은 자료를 구분한다.
